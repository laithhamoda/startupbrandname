# Changes to the SPEC

[SPEC.md](SPEC.md) is the owner's functional specification and changes only with the owner's
approval. Decisions made since it was written change parts of it; this page lists where, so the
SPEC is never read on its own. When a decision departs from the SPEC, add a row here.

For the database, the source of truth is the migrations in `supabase/migrations` and the generated
`apps/web/src/lib/supabase/database.types.ts`, not the sketch in SPEC §8.
